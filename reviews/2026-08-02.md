It's a top-three use, not #1 |

New competitor found this pass: **Callie Care** — $500K pre-seed (InterSystems Ventures), phone-first AI companion for older adults (check-ins + task help). Another companionship-only entrant; confirms the category is filling from the companionship side.

### Strongest argument against

The window is narrowing from both flanks at once: companionship-only competitors keep multiplying (inTouch, Meela, Joy Calls, now Callie Care) while the scam-shield differentiator is being built standalone (Scammer Guardian, plus free carrier/OS-level call screening improving every year). Retention past 12 weeks — the load-bearing unknown — is still supported only by a hardware-robot state program's vendor telemetry, and the thesis's own numbers from that program were inflated (50.2% → 40.1%). If the pilot retention read takes 4–6 months, the combined wedge may be occupied before the data arrives.

### Verdict: PURSUE

Every load-bearing claim survived verification intact or in slightly weaker corrected form; none was refuted. Demand (63M caregivers, $7.7B elder fraud), pricing band ($29.90–$40/mo proven by inTouch/Meela/GrandPad), and the open combined-wedge all hold. Cheapest real-world test, unchanged from the research file and still right: **~$300, 1 week — landing page ("The Senior Line — one trusted number for Mom. $39/mo") with scam-shield-led Meta creative → waitlist; kill below 8% visitor→waitlist.** Move to the 20-senior pilot only on a pass, and start it fast — the flanking argument above is a clock, not a hypothetical.

The *marketing* gap on 60+ remains, but "nobody does dating safety for this cohort" is no longer true |
| (Open item from research file) Lumen postmortem | Wikipedia, DatingSitesReviews, PitchBook | **CLOSED** — Lumen, the only prior venture-backed 50+-specific dating app, was absorbed via MagicLab into Blackstone's $3B Bumble deal (Nov 2019) and shut down Nov 2020, users folded into Bumble. The one direct precedent for a standalone 50+ dating app ended in consolidation, not a sustained business |
| Gray divorce: ~40% of divorcing Americans are 50+ | BGSU NCFMR-derived coverage | **VERIFIED** (~36–40% across sources, vs 8% in 1990) |

### Strongest argument against

Three compounding weaknesses: (1) the entire channel edge hangs on a binary, unpublished Meta authorization decision; (2) the safety wedge is narrower than pitched — SilverSingles already does verification-first, and NJ-style disclosure laws constrain how loudly "dating with a bodyguard" can be marketed anyway; (3) the only precedent for a standalone 50+ dating app (Lumen) got consolidated away rather than surviving, and this is a two-sided liquidity business — the hardest product shape in the ledger — being considered by a solo founder whose edge is paid acquisition, not community.

### Verdict: PURSUE — application-first, strictly probe-scoped

The central demand and gate claims all verified, so this can't be killed on the evidence — but it earns only the free probe: **submit Meta's dating-ads authorization application now ($0, and its outcome is the single decisive input) + a waitlist landing page (~$100).** Pre-commit to the existing kill criteria: denied authorization with no path → kill; waitlist <5% or women <40% of signups → kill. Do not write code before liquidity design for one metro exists. If Lance only has bandwidth for one bet, Senior Line ranks above this — fewer binary gates, no two-sided cold start.

## 3. Family Tree Keep-Alive (genealogy retention companion)

### Claims

| Claim | Source checked | Verdict |
|---|---|---|
| "Models Ancestry's real ~2%/mo churn once a user is invested" | Public financials search; Ancestry is Blackstone-owned (private) since 2020 | **UNSUPPORTED** — no current churn figure is public anywhere. Best public data: 3.6–3.8%/mo from Ancestry's 2012 IPO-era disclosures, i.e. nearly double the claimed number and 14 years stale |
| Core mechanic: "AI periodically surfaces new records/photos against an existing tree" is a differentiator | Ancestry product docs/blog | **REFUTED in effect** — this is Ancestry's own flagship retention feature ("Hints"/shaky leaf): continuous scanning of billions of records against your tree, with notification emails and frequency preferences, shipped since 2012. FamilySearch ships free hinting too |
| (Implied) A third party can build against an existing Ancestry tree | Genealogy-API surveys, RootsMagic API notes | **REFUTED** — Ancestry has never published a public API, restricts partner access to select desktop-sync tools, and has sent cease-and-desists to third-party tools using its data (Genome Mate Pro). The only open tree API is FamilySearch — which is free, so a churn-reduction thesis has nothing to attach to |

### Strongest argument against (was the case for it)

The retention instinct is right — invested genealogy users are sticky, and the ledger correctly flagged the family-invite growth hook. But stickiness accrues to the platform that owns the tree and the records, not to a companion bolted on beside it.

### Verdict: KILL

Single decisive reason: the product's core mechanic is the incumbent's own 14-year-old flagship feature, and there is no API through which a third party could deliver it against the trees where users actually live — Ancestry actively litigates against attempts. The central churn claim is also UNSUPPORTED, which alone bars PURSUE under this repo's rules. **This idea is currently `in-sheet` — Lance should pull it from the evaluation spreadsheet.**
