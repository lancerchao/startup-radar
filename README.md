# Startup Radar

Daily automated research digest: emerging startup opportunities, run by a scheduled Claude cloud agent.

- **`digests/YYYY-MM-DD.md`** — one per day: world-watch bullets + 2–3 deeply researched ideas.
- **`LEDGER.md`** — running deduped ledger of every idea ever surfaced, with status.
- **`PROMPT.md`** — the agent's operating manual. **Edit this file to tune the pipeline** (sources, focus areas, rubric, tone). The scheduled routine itself never needs to change.
- **`research/`** — deeper one-off research reports.

Manage the schedule at https://claude.ai/code/routines
